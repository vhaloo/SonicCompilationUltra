# Images in the settings guide

With a cartridge running, picture settings show the current game image. Open the guide with **F1**, the top gamepad face button, or the help icon. Separate illustrations explain controls and settings that do not have a useful gameplay image.

The app can also read local screenshots from `UserData/guide-captures/<game id>/`. A personal installation may include these comparisons, made from its owner's cartridges. They stay in that installation.

| Local file | Layout |
|---|---|
| `views.bmp` | Original, whole-level, panorama and PC CRT in a 2×2 grid |
| `depth.bmp` | Flat, thick, layered and sculpted in a 2×2 grid |
| `background.bmp` | Original and plain side by side |

The repository images in this folder use the app menu or an original test scene. The public downloads read your own cartridge at runtime.
