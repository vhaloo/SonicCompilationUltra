# Software, game data and distribution

Sonic Compilation Ultra is independent, noncommercial fan software. It is not affiliated with, sponsored by or endorsed by SEGA. Sonic and the game titles are the property of their respective rights holders.

## What is distributed

The executable contains cartridge-engine code, host presentation code, ROM identity/format metadata and a licensed interface font. **No cartridge ROM, BIOS, music, decoded level file, sprite sheet or reusable extracted game-art pack is distributed.** There is no ROM download endpoint or link to a pirate source.

The player chooses their own local data. The app reads that data to execute the cartridge and render its graphics. Locally assembled lock-ons and mapper helpers stay in the player's private data directory. ROM selection does not upload files anywhere.

The repository's gameplay screenshots are documentation of actual app rendering. They are not application resources, and are not labelled as original artwork owned by this project. Game pixels remain copyrighted by their rights holders; screenshot attribution does not transfer those rights. Documentation images are outside the software licence's grant for original project code.
